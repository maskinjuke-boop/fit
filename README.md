# Фитнес-тренер: симулятор

Браузерный прототип подсчёта повторов по камере телефона (ТЗ, раздел 3 и этап 1 плана).
Скелет рисуется поверх видео, повторы считаются для 7 упражнений и 2 облегчённых вариантов
подтягиваний. Видео не покидает устройство: MediaPipe работает в браузере.

## Быстрый старт

Нужны Node.js 20.19+ и pnpm 10.

```bash
pnpm install        # зависимости + копирование WASM MediaPipe в apps/web/public/wasm
pnpm models         # скачать модели pose_landmarker lite/full в apps/web/public/models
pnpm dev            # dev-сервер с HTTPS на https://<IP-компьютера>:5173
```

Откройте адрес с телефона в той же Wi-Fi сети. Сертификат самоподписанный: браузер
предупредит, нужно согласиться («Дополнительно → Перейти»). Без HTTPS браузер не даст камеру.

Проверки:

```bash
pnpm test           # 50 тестов: геометрия, фильтр, автоматы, все упражнения, записи
pnpm typecheck
pnpm build          # production-сборка в apps/web/dist
```

Для теста на телефоне без локальной сети можно залить `apps/web/dist` на любой хостинг с HTTPS.

## Что умеет

| Упражнение | Ракурс | Повтор | Проверка техники |
| --- | --- | --- | --- |
| Подтягивания | спереди или сзади | вис (локти ≥ 150°) → подбородок выше турника → вис | без раскачки |
| Негативные подтягивания | спереди или сзади | верх → вис не быстрее 3 с | без раскачки |
| Австралийские подтягивания | сбоку | локти ≥ 150° → ≤ 90° → ≥ 150° | корпус прямой |
| Отжимания | сбоку | локти ≥ 155° → ≤ 90° → ≥ 155° | корпус прямой |
| Приседания | сбоку / 45° | колени ≥ 160° → ≤ 100° → ≥ 160° | корпус ≥ 45° к полу |
| Выпады | сбоку | колени ≥ 160° → переднее ≤ 100° → ≥ 160° | корпус ≤ 20° от вертикали |
| Скручивания | сбоку | угол бедра ≥ 120° → ≤ 70° → ≥ 120° | стопы на месте |
| Джампинг-джек | спереди | руки вниз, стопы вместе → руки над головой, стопы шире плеч | руки синхронно |
| Бег на месте | спереди | каждое бедро ≥ 60° к вертикали | — |

Экран трекинга: счётчик, оценка качества 0–100, подсказка при незасчитанном повторе
(«ниже», «разогните руки»…), подсказки по кадру («отойдите дальше», «добавьте света»),
вибрация на Android, озвучка (кнопка «Голос»), экран не гаснет.

Инструменты для калибровки:

- **Отладка** — FPS, модель, GPU/CPU, разрешение входа, фаза автомата, все метрики кадра.
- **Видео** — прогон видеофайла вместо камеры; по окончании предлагается записать замер.
- **Запись** — сохраняет последовательность точек в JSON с реальным числом повторов.
  Положите файл в `apps/web/tests/fixtures/` — он станет регрессионным тестом.
- **Замер** и **Отчёт о точности** — точность, ложные засчёты и пропуски по упражнениям
  с целями ТЗ (≥ 95% и ≤ 2%), выгрузка в JSON.

## Игровой слой

- **Персонаж:** имя, путь (Атлет, Бегун, Йог — стартовая вещь и бонус), цвет, уровень подготовки, есть ли турник.
  Перед созданием — опросник о противопоказаниях и подтверждение 16+ (ТЗ, раздел 7).
- **Опыт:** XP за повтор = 10 × множитель упражнения × бонус качества 0,8–1,2; сверх дневного лимита — вдвое меньше,
  новичкам первые 14 дней лимиты ниже на 30%. Уровень = floor(40 × (L − 1)^2.2) из ТЗ.
- **Характеристики:** Сила, Ноги, Пресс, Выносливость — растут от своих упражнений.
- **Квесты:** стартовая цепочка (9), глава 1 (7), еженедельные испытания техники (7). Описаны данными в
  `src/game/quests.ts`; без турника подтягивания заменяются австралийскими (поле `alt`).
- **Ежедневки:** 3 в день по правилам ТЗ (разные группы мышц, отдых уставших групп, объём по медиане за 7 дней,
  без повторов вчерашних шаблонов), одна замена в день, сундук за все три. Боя и крафта пока нет, поэтому
  «игровой» слот — кардио или «набери N опыта».
- **Серия:** день засчитан при одном задании или 100 XP с камеры; бесплатная заморозка раз в неделю (до 2);
  +5% золота за каждые 7 дней серии.
- Вся логика — в `src/game/` (чистые функции, тесты в `tests/game.test.ts`). Прогресс пока хранится в браузере
  (`localStorage`); сервер и аккаунты — следующий этап.

## Магазин, снаряжение и 3D-персонаж

- **3D-персонаж** (three.js) — во вкладке «Персонаж», при создании героя, в редакторе внешности
  и в примерке предмета. Мужская или женская фигура, 5 оттенков кожи, 7 причёсок (короткая, ёжик,
  длинная, хвост, каре, пучок, кудри), цвет волос, 6 цветов глаз, борода, цвет одежды. Модель строится
  прямо в коде, без файлов моделей.
- **Тело:** готовая модель MakeHuman (makehumancommunity.org, лицензия CC0, без обязательной атрибуции) —
  женская и мужская формы с реалистичными пропорциями, поставленные в игровую позу (руки опущены, кисти
  сжаты под ручку) по скелету и весам MakeHuman. Голова и тело взяты из одной модели и стыкуются по шее.
  Для одежды по сетке тела строится поле расстояний, так что слои одежды облегают именно эту фигуру.
  Данные — `bodyData.ts`, код — `bodyMesh.ts`, `anatomy.ts`.
- **Одежда по фигуре:** каждый слой — оболочка того же тела с маской области (футболка, майка, спортивный
  топ, кроп-топ, худи, купальник, корсет, брюки, леггинсы, шорты, чулки, ботфорты…), поэтому одежда облегает фигуру,
  края скруглены как подогнутый шов. Сетки строятся порциями, не подвешивая интерфейс («Лепим героя…»),
  и сохраняются в IndexedDB — при следующих запусках загружаются за доли секунды.
- **Лицо и волосы:** голова — готовая модель MakeHuman (makehumancommunity.org, лицензия CC0,
  без обязательной атрибуции): женская и мужская формы с правильными пропорциями лица, носом, губами
  и ушами; сетка сглаживается делением по Лупу. Ползунки лица — мишени MakeHuman (ширина, скулы, челюсть,
  подбородок, нос, губы). Данные — `headData.ts` и `bodyData.ts`, их создаёт `apps/web/scripts/extract-mh.py`
  из репозитория MakeHuman; форма черепа для волос и шапок берётся лучами по этой сетке. Плечи — трапеции со скатом к плечу,
  ключицы, мышцы шеи, дельтовидные мышцы; глаза с радужкой и моргающими веками стоят в глазницах модели, ресницы растут по краю её век. Кожа — физический материал с тёплым отливом по краям, волосы — с анизотропным бликом.
  Причёски — готовые системные причёски MakeHuman (CC0): сетки из карточек с текстурой прядей,
  сделанные для той же модели головы (короткая, ёжик, длинная, хвост, каре, пучок, кудри). Привязка
  к базовой сетке взята из пакета проекта Body Studio (github.com/gpspelle/body-studio), текстуры —
  яркость прядей в `public/hair/*.webp`, цвет задаёт материал. Под шапкой, кепкой или шляпой волосы
  прижаты к голове; длинные волосы ложатся поверх одежды. Борода —
  из прядей с открытым ртом. Кнопка «Лицо» приближает камеру. Код: `head.ts`, `hair.ts`, `hairMesh.ts`.
- **Редактор тела и лица:** в создании героя и в «Изменить внешность» — ползунки от минимума до максимума
  по группам: общее (рост, телосложение «худее — полнее», мышцы), верх тела (плечи, грудь, руки, шея),
  корпус (талия, живот), бёдра и ноги (бёдра, ягодицы, ноги) и лицо (ширина, скулы, челюсть, подбородок,
  нос, губы, глаза, брови). Тело меняется плавной деформацией вместе с одеждой — без повторной
  «лепки», поэтому герой обновляется сразу; превью остаётся на экране, пока листаете ползунки.
  Код: `src/ui/game/three/morph.ts`, `src/ui/game/AppearanceEditor.tsx`.
- **Графика:** процедурные текстуры (ткань, деним, трикотаж, кожа, сетка, кружево, пайетки, волосы,
  шлифованный металл), лак латекса, атлас и бархат с отливом, отражения металла и стекла от студийного
  окружения, мягкие тени, контровой свет в цвете героя. Герой дышит, моргает и покачивает головой.
  Если телефон не тянет, тени отключаются и чёткость снижается автоматически.
- **Картинки из 3D:** иконки предметов в магазине и сумке и портрет в шапке рендерятся из тех же
  3D-моделей одним скрытым холстом. Без WebGL или до загрузки three.js показываются векторные варианты
  (`src/ui/game/Avatar.tsx`). Код 3D: `src/ui/game/three/`.
- **Магазин:** 130 современных вещей в 9 слотах: голова (15), шея (12), верх (24), спина (11), руки (11),
  низ (18), обувь (15), «в руке» (14) и «сумка» (10). Город и спорт: бейсболка, бини, наушники, худи,
  спортивный костюм, кимоно, леггинсы, беговые кроссовки, фитнес-браслет, медаль марафонца, гантель,
  гиря, шейкер, коврик для йоги, спортивная сумка. Повседневное и свидания: джинсы и рваные джинсы,
  рубашка, юбка-карандаш, туфли на шпильке (свой каблук и платформа у кед), часы, кофе с собой,
  смартфон, зонт, букет роз, гитара, скейт, шоппер, портфель, клатч, корзинка для пикника.
  Вечеринки и клуб (игра для взрослых, но без наготы — грудь и пах всегда закрыты): кошачьи и кроличьи
  ушки, рожки и нимб, маска для маскарада, фата, бикини, боди, латексные корсет и комбинезон, сетчатый
  топ, портупея, чулки в сетку и с подвязками, ботфорты, перчатки до локтя, крылья ангела, демона и феи,
  бокал шампанского, микрофон, дизайнерская сумка на цепочке. Женские топы без мужского варианта
  (бандо, бикини, топ на завязке) на мужской фигуре не рисуются, а иконку показывают на женской.
  Рецепты одежды и аксессуаров: `src/ui/game/three/wardrobe.ts`, вещи в руках: `src/ui/game/three/items3d.ts`.
  Средневековые вещи из прежних версий убраны; старые сохранения переводятся на похожие современные
  (`RENAMED_ITEMS` в `src/game/items.ts`: гамбезон → худи, фляга зелья → бутылка воды, лютня → гитара,
  кожаные башмаки → кроссовки и т. д.), а оружие и доспехи без пары просто исчезают. В окне предмета
  есть переключатель «Примерить 3D». Покупка за золото с требованием уровня, купленный предмет сразу
  надевается. Цены — от 60 до 3500, уровни — от 1 до 12, редкость от обычной до легендарной; предметы дают
  до +10% опыта, суммарно не больше +25%. Каталог: `src/game/items.ts`. У каждого пути есть стартовый предмет.
- **Хват:** кисть сжимается в кулак по скелету MakeHuman — каждый палец сгибается вокруг своей
  поперечной оси, большой палец обхватывает ручку с другой стороны (`fist()` в `scripts/extract-mh.py`).
  Вещь «в руке» держится в правой руке, сумка — в левой, у каждой вещи своя поза (`HOLD` в `items3d.ts`):
  телефон — экраном вперёд, стакан и бокал — стоя, гантель — за гриф, ракетка и зонт — за ручку вниз,
  гитара — за гриф, сумки, гиря и скейт висят под кулаком за ручку или ребро.
- **Снаряжение** — во вкладке «Персонаж»: девять слотов и рюкзак на 160 ячеек с картинками предметов, общий бонус, смена внешности.

## Симулятор фитнес-тренера

Вкладка «Тренер» — жизнь героя-тренера в двух локациях: **свой частный дом** и **фитнес-зал**. Время идёт
действиями (часы в углу), день сменяется ночью.

- **Ученики.** Сначала на платные занятия ходит один очень полный человек. С уровнем героя учеников
  становится больше (1 + каждые 2 уровня, до вместимости зала), а новые приходят всё более спортивными.
  Каждое занятие делает учеников стройнее и крепче (меняется их 3D-фигура и одежда); без занятий и при
  пропущенной норме падает доверие, ученик с нулевым доверием уходит.
- **Занятие.** В зале встаньте на оранжевый круг перед учениками → «Провести занятие» → выберите
  упражнение. Вы выполняете его перед камерой, а 3D-ученики поверх видео повторяют каждое засчитанное
  движение (полные — чуть медленнее). Число повторов растёт с уровнем. Оплата =
  (10 + 4·уровень) × множитель зала × число учеников (+ бонус обаяния); при выходе раньше — за выполненную часть.
- **Зал** улучшается у ресепшена (нужны уровень и деньги): гаражный зал → зал у дома → фитнес-студия →
  фитнес-клуб → премиум-центр. Больше мест и дороже занятия, в сцене появляются стойки, дорожки, груши,
  душевая и фитнес-бар. Зал открыт с 6:00 до 23:00.
- **Норма дня.** Каждый реальный день нужно сделать обязательное число повторов перед камерой
  (20 + 5 за уровень, до 120; фиксируется утром). Не сделали — штраф (20 + 8·уровень за день, до трёх
  дней) и потеря доверия учеников. Прогресс нормы — в углу экрана.
- **Дом:** кровать, холодильник (продукты, доставка), плита, душ, диван с телевизором, зеркало (речь
  тренера → обаяние) и дверь в зал; в телефоне покупается мебель (компьютер — онлайн-консультации,
  коврик и гантели — своя тренировка, мольберт — программы тренировок и др.).
- **Потребности** (сытость, энергия, гигиена, отдых, общение), **навыки** (кулинария, обаяние, логика,
  творчество), **утренние события** (блогер, спонсор, поломка, торт от ученицы…).
- **Самостоятельный сим.** Если 6 секунд не трогать управление, сим сам выбирает самое нужное
  действие (голоден — ест или готовит, нет продуктов — заказывает, грязный — в душ, ночью и без сил —
  спать, поздно в зале — домой), подходит к предмету и пользуется им; над сценой видно, что он задумал.
  Любое касание возвращает управление. Занятия и тренировки перед камерой сим без игрока не начинает.
  Кнопка 🤖 «Сам / Вручную» выключает самостоятельность.
- **Масштаб:** колесо мыши, щипок двумя пальцами или кнопки ＋/− справа; выбранный масштаб запоминается.
- **Тени:** персонажи отбрасывают тень на пол, но не на себя (без тёмных пятен от рук и волос на теле).
- **Анимация.** У персонажей есть скелет (16 костей, веса кожи считаются по частям тела): ходьба героя,
  стойка с дыханием, разминка учеников в зале и все упражнения занятия (приседания, выпады, отжимания,
  скручивания, «джампинг-джек», бег с высоким подниманием колен). Ограничение: длинные рукава при
  поднятых руках слегка тянут ткань к боку — поэтому ученики занимаются в майках и топах.
- Код: `src/game/life.ts` (логика, в том числе выбор действий сима — `autoAction`), `src/game/lifeContent.ts` (предметы, залы, упражнения, действия,
  события), `src/game/lifeMap.ts` (раскладка сцен), `src/ui/game/three/LifeScene3D.tsx` (3D дом и зал),
  `src/ui/game/three/SessionCrew3D.tsx` (ученики на занятии), `src/ui/game/three/rig.ts` (скелет и
  движения), `src/ui/game/Life.tsx` (интерфейс). Тесты: `tests/life.test.ts`.

## Режим администратора

Откройте сайт со ссылкой `?admin` (например, `https://<сайт>/?admin`) — появится красная кнопка ⚙.
Там: золото и опыт, установка уровня, имитация повторов любого упражнения с заданным качеством
(через настоящий игровой движок), выполнение заданий дня и активных квестов, возврат замены задания,
выдача всех предметов, все потребности на максимум, перемотка игрового времени по дням (проверка серии и новых ежедневок),
выгрузка сохранения в JSON. Выключается кнопкой в панели или ссылкой `?admin=0`.
Сохранение, изменённое администратором, помечается флагом `adminTouched`.

## Как устроен подсчёт

```
MediaPipe (33 точки) → проверка кадра → One Euro Filter → метрики упражнения
→ конечный автомат «старт → пик → старт» с гистерезисом → событие повтора / причина отказа
```

- `src/tracking/` — ядро без браузера и MediaPipe, полностью покрыто тестами.
- `src/tracking/exercises/thresholds.ts` — **все пороги в одном файле**, их и нужно калибровать.
- `src/tracking/exercises/*.ts` — каждое упражнение = метрики + описание автомата.
- `src/tracking/repStateMachine.ts` — общий автомат: гистерезис, минимальная длительность,
  проверки техники, оценка качества.
- `src/pose/` — обёртка MediaPipe (GPU → CPU, смена модели и разрешения при FPS < 15).
- `src/ui/` — интерфейс, `src/i18n/` — русский и английский.

Решения, принятые сверх ТЗ (их стоит проверить на реальных видео):

- Длительность повтора считается от последнего кадра в стартовой зоне, а не от выхода из
  зоны гистерезиса — иначе быстрые и медленные повторы мерились бы неточно.
- Вис ≥ 0,3 с требуется перед первым подтягиванием; между повторами — нет, чтобы не
  отбрасывать нормальные повторы с короткой паузой. Раскачку отсекает проверка бёдер.
- Линия турника — медиана высоты запястий за первые 2 с, пока руки выше плеч;
  при съёмке сзади подбородок оценивается по ушам.
- Бег на месте спереди: угол бедра оценивается по высоте колена относительно таза
  (бедро, поднятое вперёд, в кадре укорачивается, а не поворачивается).
- Камера по умолчанию фронтальная, чтобы человек видел счётчик.

## Статус проверки

- Логика подсчёта проверена 50 тестами на синтетических движениях (полные, половинчатые,
  быстрые повторы, нарушения техники, потеря человека в кадре, кадр 16:9 и 9:16).
- Интерфейс прогнан в Chromium с имитацией камеры и позы: выбор упражнения, скелет,
  счёт повторов, подсказки, замер, отчёт — без ошибок в консоли.
- **С настоящей моделью MediaPipe прототип ещё не запускался** — это первый шаг на
  вашей стороне (см. ниже). Пороги в `thresholds.ts` — стартовые значения из ТЗ.

## Что сделать для приёмки этапа (критерий: точность ≥ 90%)

1. Запустить на телефоне, проверить каждое упражнение вживую с включённой «Отладкой».
2. Снять по 3–5 коротких видео на упражнение с известным числом повторов, прогнать через
   «Видео», сохранить замеры и записи.
3. Подправить пороги в `thresholds.ts` по метрикам из отладки, добавить записи в
   `tests/fixtures/`, добиться точности ≥ 90% в «Отчёте о точности».
4. Проверить FPS на Galaxy A54 (≥ 20) и iPhone 12 (≥ 30).
